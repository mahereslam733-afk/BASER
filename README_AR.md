# أبصار AI

نسخة أولية جاهزة كتطبيق ويب تقدمي (PWA) مصمم بواجهة عالية التباين وأزرار كبيرة ودعم صوتي عربي.

## الوظائف الموجودة
- قراءة النصوص من الكاميرا/صورة باستخدام OCR.
- التعرف على الأشياء: واجهة الكاميرا جاهزة للربط بمحرك رؤية اصطناعية.
- التعرف على العملات: واجهة الكاميرا جاهزة لربط نموذج العملات.
- طلب مساعدة بشرية عبر واتساب.
- فتح الملاحة مع الموقع.
- محتوى صوتي.
- خدمات يومية.
- دعم أساسي للعمل بدون إنترنت للواجهة.
- أوامر صوتية عربية.
- إمكانية التثبيت على شاشة الهاتف كتطبيق.

## تشغيله
1. ارفع الملفات إلى GitHub.
2. فعّل GitHub Pages للمستودع.
3. افتح رابط الموقع من Chrome على الهاتف.
4. من قائمة Chrome اختر "إضافة إلى الشاشة الرئيسية" أو استخدم زر "تثبيت التطبيق".

## ملاحظة مهمة
التعرف المتقدم على الأشياء والعملات يحتاج نموذج رؤية اصطناعية فعليًا. هذه النسخة تحتوي الواجهة والكاميرا وتجهيز الربط، بينما OCR للنصوص يعمل عند توفر مكتبة Tesseract عبر الإنترنت.
